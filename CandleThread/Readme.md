# Python Candle Thread
This file demonstrates how a thread object is started and continuously loads 
candle data from the public api of the binance cryptoexchange

- Start the GUI
- choose the crypto currency and timeframe to your likings via dropdown menu ('1m' = fast results)
- Press 'Start' Button 
- check the candles forming
- Future plan: connect it to a tensorflow time row estimator and automatically create orders
